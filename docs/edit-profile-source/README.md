# Noctra — окно «Редактировать профиль»

Исходник текущего окна `#np-edit-sheet` / `.npe-card` (Edit Sheet 3.0).

## Файлы

| Файл | Что внутри |
|---|---|
| `edit-profile.rendered.html` | Снятый с работающего приложения HTML окна |
| `edit-profile.js` | IIFE из `mobile/mobile-ui.js:2321-2552`: шаблон, предпросмотр, баннер, эффекты, сохранение |
| `edit-profile.css` | Актуальный файл `mobile/edit-profile.css`, подключается последним |

## Как устроено

Статической разметки в `index.html` нет: `buildSheet()` создаёт `#np-edit-sheet`
с `.npe-backdrop` и `.npe-card` и добавляет его в `<body>`. Открытие
перехватывается кликом по `#np-edit-profile` на странице профиля.

JS отвечает за:

- текущий профиль (`MurielProfiles.current()`);
- хранение аватара, баннера, био и эффекта в `localStorage` (`noctra_profile_extra_v1`);
- чтение выбранного файла через `FileReader` в data URL (отдельные input для аватара и баннера);
- живой предпросмотр: аватар, баннер, ник, уровень/XP, био, эффект;
- кнопку-камеру на аватаре и клик по самому аватару (выбор файла), плюс `×` для сброса;
- эффекты `none / embers / fog / aurora / stars` через `.np-profile-fx.fx-*`;
- сохранение и вызов `applyExtras()` на странице профиля;
- закрытие по `×`, «Отмена», фону и `Escape`.

## CSS

Файл `mobile/edit-profile.css` загружается после `mobile.css` и остальных
мобильных слоёв, поэтому задаёт финальный вид окна и эффектов профиля.
Использует переменные темы (`--md-sys-color-primary`, `--safe-bottom`), но
поверхности/акценты листа заданы в фиксированной фиолетовой гамме, как в
макете.

Ключевые блоки:

- `.np-profile-fx` — атмосферные эффекты профиля;
- `#np-edit-sheet` — оверлей снизу, `z-index: 4200`;
- `.npe-card` — нижний лист с `max-height: 92dvh`;
- `.npe-preview` / `.npe-prev-*` — карточка живого предпросмотра;
- `.npe-section` — секции настроек;
- `.npe-fx-grid` / `.npe-effect` — сетка эффектов;
- `.npe-actions` — липкий футер.
